# DECISIONS — ความจำและข้อสรุปถาวร

> เก็บ facts, preferences และ decisions ที่ยังมีผล ใช้ remember/forget ผ่าน
> `$project-memory` เพื่อ add, replace หรือ supersede โดยอ่านไฟล์นี้ทั้งไฟล์ก่อนเสมอ

## รูปแบบ

```md
### D-001: <ข้อสรุปสั้น>
- Status: active | superseded | removed
- Decided: YYYY-MM-DD
- Decision: <สิ่งที่ต้องจำ>
- Why: <เหตุผล ถ้ามี>
- Source: <ไฟล์/วันที่/session ที่ตรวจย้อนกลับได้>
```
